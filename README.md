# watcHaven ⌚

Een virtuele watchbox applicatie voor horlogeliefhebbers.

## Functies

### 1. Horloge Database
- Bekijk een uitgebreide database met 10 verschillende horloges
- Voeg horloges toe aan je collectie of wishlist
- Bekijk details per horloge (merk, model, prijs, referentienummer)

### 2. Watchbox
- **Collectie Beheer**: Voeg horloges toe aan je persoonlijke collectie
- **Wishlist**: Houd bij welke horloges je nog wilt aanschaffen
- **Statistieken**:
  - Totale waarde van je collectie
  - Aantal horloges in collectie en wishlist
  - Verdeling per merk (percentage en absolute aantallen)
- **Logboek**: Log wanneer je een horloge draagt
- **Meest Gedragen**: Zie welke horloges je het meest draagt

### 3. Interactieve Wristcheck
- Upload een foto van je pols of kies een preset
- Selecteer een horloge uit de database
- Pas het horloge aan met:
  - Schaal (grootte)
  - X en Y positie
  - Rotatie
- Sla je wristcheck op als afbeelding

## Gebruik

Open `index.html` in een moderne webbrowser. De applicatie werkt volledig client-side en slaat je gegevens op in localStorage.

## Technologie

- Vanilla HTML5, CSS3, en JavaScript
- LocalStorage voor data persistentie
- Canvas API voor wristcheck functionaliteit
- Responsive design voor mobiel en desktop
